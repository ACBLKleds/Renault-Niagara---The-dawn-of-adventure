## 🚀 Subir a Netlify

1. Andá a https://netlify.com
2. "Add new site" → "Deploy manually"
3. Arrastrá los 3 archivos: `dia1_preshow.html` + `dia2_reveal.html` + `bg_vertical.jpg`
4. Listo. Las URLs serán:
   - `https://tunombre.netlify.app/dia1_preshow.html`
